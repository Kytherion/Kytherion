## 💡 Engineering Philosophy

I believe good software engineering is about more than writing code.

My approach focuses on:

-   **Clean Code:** Writing readable, maintainable and reusable code.
-   **Software Architecture:** Building scalable and reliable backend
    systems.
-   **Security:** Treating data protection and secure processing as
    essential engineering requirements.
-   **Reliability:** Designing applications that remain stable in
    demanding production environments.
-   **Continuous Improvement:** Modernizing existing systems and
    adopting technologies that bring real engineering value.
-   **Ownership:** Following software throughout its lifecycle, from
    technical design to production support.
-   **Curiosity:** Continuously exploring new technologies and
    challenging myself to learn beyond my current expertise.

I also explore generative AI tools as engineering assistants for code
analysis, debugging and implementation exploration, while maintaining
responsibility for reviewing and validating generated solutions.
